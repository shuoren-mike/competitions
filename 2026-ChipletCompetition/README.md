# AgenticChipletDesign

**First Prize — Chiplet Competition (3rd edition), Shanghai, 2026**

Competition presentation on **Agent-Guided Cross-Layer Chiplet Optimization** by the **FlynnCarry Team**, The Chinese University of Hong Kong.

## Competition

- **Competition:** 第三届集成芯片和芯粒技术大赛
- **Track:** Academic Challenge 2 — Automated Cross-Layer Optimization of Integrated Chips Using Agentic AI
- **Defense date:** 9 October 2026
- **Location:** Shanghai, China
- **Award:** First Prize

## Project

The project combines agent-assisted analysis and design-space exploration with workload implementation and hardware configuration optimization. The presentation covers the optimization process, evaluation results, and technical discussion.
