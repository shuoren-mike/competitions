# Thermal-Aware 3D Chiplet Placement

**First Prize — Chiplet Competition (2nd edition), Wuhan, 2025**

Competition presentation by the **FlynnCarry Team**, The Chinese University of Hong Kong.

## Competition

- **Competition:** 第二届集成芯片和芯粒技术大赛
- **Track:** 合见工软产学融合赛题 — 面向 3D 集成电路的热感知芯粒布局
- **Location:** Wuhan, China
- **Award:** First Prize

## Project

The competition solution addresses thermal-aware 3D chiplet floorplanning using an FM–ILP hybrid approach. The presentation covers the problem formulation, algorithm design, placement constraints, and experimental results for temperature and wirelength.

This competition prototype preceded our later Chiplet3D research.
